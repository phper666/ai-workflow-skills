# 变更摘要模板

共识文档业务规则变更时生成。最新在前，单条 ≤200 字。供 change-propagation 消费。

```markdown
## 变更摘要

| 项 | 内容 |
|:---|:-----|
| 规则编号 | CON-R012 |
| 旧结论 | 订单取消后库存即时回补 |
| 新结论 | 订单取消后延迟 24 小时回补 |
| 生效时间 | 2026-08-15 起 |
| 变更人 | 赵六（PM） |
| 变更类型 | 语义变更（非破坏兼容） |
| 共识版本 | v1.1 |
| 关联 Q-items | Q-007（幂等策略） |
| 变更理由 | 业务侧决定：规避用户取消后立即退货产生的库存波动 |
```

## 变更类型参考

- 语义跟随：描述/取值变化，无兼容影响
- 破坏兼容：字段删除、接口路径/类型变化、行为反转
- 敏感类：涉及权限、数据、资金、状态机、事务、隔离
- 新增：新增规则（非变更，若影响下游同样传播）
