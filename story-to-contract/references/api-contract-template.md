# 前后端接口契约模板

只保留当前有效契约。`{...}` 为占位符，不得原样留在最终文档。

## 允许的顶级章节

1. 契约信息
2. 需求与共识追踪
3. 范围与非目标
4. 业务流程与状态
5. 接口清单
6. Schema 与枚举
7. 接口详情
8. 数据库与外部系统影响（按需）
9. 联调与测试场景
10. 开放问题
11. 协调事项
12. 完成记录
13. 决策与踩坑
14. 变更记录
15. 自检记录

禁止新增“历史方案”“审查过程”“已闭环说明”“版本立场链”等过程章节。决策与踩坑只保存可复用知识，不写当前规格的过程叙述。
