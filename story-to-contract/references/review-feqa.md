# FE/QA 契约复核规约

复核只查"实现契约问题"（FE 联调可用性 + QA 可测试性），**不重新猜测产品规则**——产品规则疑问走待确认闭环（consensus-scan），不在此解决。

## FE 复核视角（联调可用性）

- [ ] 字段覆盖：响应字段覆盖交互所需（列表、详情、空态、操作后刷新所需数据）
- [ ] 错误处理：错误码足以区分参数错误 / 未认证 / 无权限 / 不存在 / 状态冲突 / 业务校验 / 限流 / 依赖失败 / 超时
- [ ] 示例自洽：请求/响应示例可执行，无占位值
- [ ] Mock/OpenAPI 一致：Mock 与文档示例一致，字段不漂移
- [ ] 分页/排序/筛选：前端列表所需的语义已定义
- [ ] 时间/时区/格式语义明确

## QA 复核视角（可测试性）

- [ ] 每个接口有成功场景 + 失败场景（参数/权限/冲突/依赖失败）
- [ ] 边界值可识别（枚举越界、空串、超长、特殊字符、并发）
- [ ] 每条测试场景绑定验收编号（可追溯到共识/Story）
- [ ] 敏感字段不出现在响应示例和日志示例中
- [ ] 联调与测试场景表可直接执行（前置条件/请求/预期响应齐全）

## 输出

- 通过：契约状态置"待评审→已冻结"（两轮复核通过）
- 退回：意见清单（问题 + 位置 + 必须/建议），BE 修改后重新复核
- 阻断级问题登记进契约"开放问题"，不得冻结

## 纪律

- 复核发现产品规则疑点 → 不进本清单，转 Q-items 待确认闭环
- 两轮复核仍剩 Blocker → 停止并报告，不自我循环
- 复核通过才允许 FE 联调准备和 QA 用例生成进入执行
