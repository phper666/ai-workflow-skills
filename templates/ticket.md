# Ticket 模板 v1

> 版本纪律：只增不改名；schema 变更走版本头 bump

## Summary（身份，创建后冻结）

[T-<编号>][<模块>][<需求标识>] <一句话（≤50字）>

- 正则：`^\[(T-\d+)\]\[([^\]]+)\]\[([^\]]+)\]\s*(.+)$`
- ticket 有原生 key（DH-12/task_guid）即跨载体身份，T-编号是辅助

## 字段

- status: 载体原生流程（todo/doing/done 映射）
- 优先级 / 负责人：载体原生

## Description 六区（冻结区）

1. 背景目标：为什么做，来源（父 Story key / PRD / 共识章节）
2. 范围：做什么 / 非目标（显式列出，防蔓延）
3. 验收：绑定 AC 编号（契约）
4. 依赖与待确认项：P0 必列（缺项 → 打回）
5. 产物与导航：设计 / 契约 / PRD 链接
6. DoD：完成定义清单

## 评论：见 comment.md（ticket 注册表）
